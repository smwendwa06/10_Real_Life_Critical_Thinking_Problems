# 10 Real-Life Critical Thinking Problems (Java)

Solutions for Weeks 1-5 (Scanner, conditionals, loops, arrays, ArrayList).
Each file is standalone: `javac ProblemXX_Name.java && java ProblemXX_Name`

| # | File | Key concepts |
|---|------|--------------|
| 1 | MpesaFloat1 | for loop, switch, ArrayList history, file save |
| 2 | FeeTracker2 | arrays, do-while, overpayment/index validation |
| 3 | TrafficLight3 | boolean, modulus, cycles |
| 4 | BarcodeChecker4 | String, charAt, check digit |
| 5 | TemperatureMonitor5 | double[], stats, stability, text chart |
| 6 | BodaFare6 | if-else-if, surcharges, rounding, file save |
| 7 | Attendance7 | 2D array, nested loops |
| 8 | AirtimeInventory8 | parallel arrays, menu, file save |
| 9 | WaterBill9 | tiered pricing, bill formatting, file save |
| 10| Library10 | ArrayLists, menu, file save/load |

All programs validate input and show a summary; several save data to a text file.
